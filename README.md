# RetailPro - Proyecto de Data Analytics

## Descripción

Este repositorio contiene el desarrollo del proyecto **RetailPro**, realizado como parte del curso de Data Analytics. El objetivo del proyecto es analizar información de ventas, clientes, productos y categorías para obtener indicadores que faciliten la toma de decisiones comerciales y contribuyan a mejorar la rentabilidad del negocio.

A lo largo del proyecto se trabajó con modelado de bases de datos, consultas SQL, procesos ETL, modelado de datos y visualización mediante dashboards en Power BI.

## Cómo ejecutar los scripts SQL

1. Abrir **pgAdmin 4**.
2. Conectarse a una instancia de PostgreSQL.
3. Crear una nueva base de datos para el proyecto.
4. Abrir el **Query Tool**.
5. Ejecutar primero el script de creación de tablas.
6. Ejecutar el script de carga de datos.
7. Ejecutar las consultas SQL correspondientes a cada módulo para analizar la información.
